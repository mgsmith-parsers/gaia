## ஒரு பார்வை

`GaiaBuilder` என்பது [`GaiaParser`](GaiaParser-Tamil.md)-இன் எதிர்த் திசை இணை: பயன்பாட்டு அடையாளங்காட்டி (AI) மற்றும் மதிப்பு இணைகளின் தொகுப்பை இது நன்கமைந்த GS1 **உறுப்புச் சரமாகவோ** அல்லது **GS1 Digital Link URI-ஆகவோ** மாற்றுகிறது. நீங்கள் AI-களையும் அவற்றின் முழுத் தரவு மதிப்புகளையும் தருகிறீர்கள்; கட்டமைப்பான் அவற்றை இணைத்து, `GaiaParser` பயன்படுத்தும் அதே இயந்திரத்தால் முடிவைச் சரிபார்த்து, பின்னர் வெளியீட்டைத் தருகிறது.

கட்டமைப்பான் *தன் சொந்த முன்மொழிவு வெளியீட்டையே பாகுபடுத்திச்* சரிபார்ப்பதால், அது திருப்பித் தரும் அனைத்தும் `GaiaParser` மூலம் குறையின்றிப் பாகுபடுத்தப்படும் என உறுதி — எது நன்கமைந்தது என்பதில் இவ்விரண்டும் ஒருபோதும் முரண்பட முடியாது.

**நுழைவுப் புள்ளி வகுப்பு:** `tools.pantheum.gaia.GaiaBuilder`

## GS1 மற்றும் General Specifications பற்றி

**GS1** என்பது வழங்கல் சங்கிலி அடையாளம் மற்றும் தரவுப் பரிமாற்றத்திற்கான திறந்த தரநிலைகளை உருவாக்கி பராமரிக்கும் உலகளாவிய இலாப நோக்கற்ற அமைப்பு. அதன் தரநிலைகள் சில்லறை வணிகம், சுகாதாரப் பராமரிப்பு, தளவாடம், உணவுச் சேவைகள் மற்றும் பல தொழில்களில் பயன்படுகின்றன; நுகர்வோர் பொதியிலுள்ள பொருள் பார்கோடு தொடங்கி மருந்து அளவுகளின் வரிசை எண் அடிப்படையிலான கண்காணிப்பு வரை அனைத்தையும் இவை உள்ளடக்குகின்றன.

இந்தக் கட்டமைப்பான் செயல்படுத்தும் அனைத்திற்கும் அதிகாரப்பூர்வ ஆதாரம் **GS1 General Specifications** — இந்த ஒற்றை ஆவணமே பின்வருவனவற்றை வரையறுக்கிறது:

- அனைத்து பயன்பாட்டு அடையாளங்காட்டி (AI) குறியீடுகள், அவற்றின் தரவுத் தலைப்புகள், வடிவங்கள், சரிபார்ப்பு விதிகள்
- AI உறுப்புச் சரங்களை உருவாக்கவும் குறியாக்கம் செய்யவும் தேவையான தொடரமைப்பு விதிகள்
- பார்கோடு குறியீட்டு முறைக்கான தேவைகள் மற்றும் AIM குறியீடு ID ஒதுக்கீடுகள்
- கட்டுப்பாட்டு இலக்கம் மற்றும் கட்டுப்பாட்டு எழுத்து வழிமுறைகள்
- இரு இலக்க ஆண்டு தீர்மானம் (நகரும் சாளர விதி)
- Data Matrix, QR Code, GS1-128, GS1 DataBar மற்றும் பிற ஏந்திகளின் விவரக்குறிப்புகள்

GS1 General Specifications ஆண்டுதோறும் புதுப்பிக்கப்படுகிறது. தற்போதைய பதிப்பும் துணை ஆவணங்களும் இங்கே கிடைக்கின்றன:

> **[https://www.gs1.org/standards/gs1-general-specifications](https://www.gs1.org/standards/gs1-general-specifications)**

GS1 General Specifications-இன் **வெளியீடு 26.0 (அங்கீகரிக்கப்பட்டது, ஜனவரி 2026)**-ஐ GAIA செயல்படுத்துகிறது.

GS1 Digital Link URI-கள் **GS1 Digital Link: URI Syntax** எனும் துணைத் தரநிலையின் கீழ் வருகின்றன. முதன்மை அடையாளச் சாவிகள், சாவி தகுதிப்படுத்திகளின் வரிசை, தரவுப் பண்புக் குறியாக்கம் ஆகியவற்றை அதுவே வரையறுக்கிறது — Digital Link URI-களை உருவாக்கும்போது கட்டமைப்பான் இவற்றையே பயன்படுத்துகிறது:

> **[https://ref.gs1.org/standards/digital-link/uri-syntax/](https://ref.gs1.org/standards/digital-link/uri-syntax/)**

GS1 Digital Link: URI Syntax தரநிலையின் **வெளியீடு 1.7.0 (அங்கீகரிக்கப்பட்டது, ஆகஸ்ட் 2026)**-ஐ GAIA செயல்படுத்துகிறது.

இந்த ஆவணத்தில் உள்ள பிரிவுக் குறிப்புகள் GS1 General Specifications-ஐச் சுட்டுகின்றன (எ.கா. "Table 7-5", "section 7.12"); Digital Link பிரிவு எண்கள் (எ.கா. "§4.9", "§4.12") மட்டுமே விதிவிலக்கு — அவை GS1 Digital Link: URI Syntax தரநிலையைச் சுட்டுகின்றன.

## விரைவுத் தொடக்கம்

```java
import tools.pantheum.gaia.GaiaBuilder;

// Element string
String es = GaiaBuilder.create()
        .ai("01", "09506000134352")
        .ai("10", "LOT-ABC")
        .ai("17", "271231")
        .buildElementString();
// 0109506000134352 10 LOT-ABC <GS> 17 271231   (GS = FNC1 group separator, 0x1D)

// GS1 Digital Link URI (canonical, on https://id.gs1.org)
String dl = GaiaBuilder.create()
        .ai("01", "09506000134352")
        .ai("10", "LOT-ABC")
        .ai("17", "271231")
        .buildDigitalLinkUri();
// https://id.gs1.org/01/09506000134352/10/LOT-ABC?17=271231
```

மூல AI நேரெழுத்துகளுக்குப் பதிலாக `GS1Constants_AICodes` மாறிலிகளைத் தேர்வு செய்யுங்கள் (பார்க்க [பாகுபடுத்தி வழிகாட்டியின் இணைப்பு அ](GaiaParser-Tamil.md#இணபப-அ--ai-சர-மறலகள)):

```java
import static tools.pantheum.gaia.gs1.constants.GS1Constants_AICodes.*;

String es = GaiaBuilder.create()
        .ai(AI_01_GTIN, "09506000134352")
        .ai(AI_10_BATCH_LOT, "LOT-ABC")
        .buildElementString();
```

## இது எப்படி இயங்குகிறது

ஒவ்வொரு கட்டமைப்பும் ஒரே பாதையிலேயே செல்கிறது:

1. **இணைத்தல்** — AI/மதிப்பு இணைகள் சேர்ந்து ஒரு முன்மொழிவு உறுப்புச் சரமாகின்றன. *பிரிப்பான் தேவைப்படும்*, கடைசி உறுப்பு அல்லாத ஒவ்வோர் AI-க்குப் பின்னும் FNC1 குழுப் பிரிப்பான் (`0x1D`) செருகப்படுகிறது. நீளம் முன்பே அறியப்பட்ட AI-களுக்கு (GTIN, தேதிகள், நிலையான-நீள அளவீடுகள்) பிரிப்பான் கிடையாது; மற்றவற்றுக்கு உண்டு. (அறியப்படாத AI-கள் இந்தப் படிக்கே வருவதில்லை — `ai(...)` அவற்றை உடனே நிராகரிக்கிறது; பார்க்க [உறுப்புச் சரங்களைக் கட்டமைத்தல்](#உறபபச-சரஙகளக-கடடமததல).)
2. **சரிபார்ப்பு** — முன்மொழிவை `GaiaParser` `CONTENT` முறையில் பாகுபடுத்துகிறது. ஒவ்வொரு மதிப்பும் அதன் AI வடிவத்திற்கும் கட்டுப்பாட்டு இலக்கத்திற்கும் எதிராகச் சோதிக்கப்படுகிறது; அமைப்பு விதிகள் (கட்டாய மற்றும் விலக்கப்பட்ட AI இணைகள்) செயல்படுத்தப்படுகின்றன. பாகுபடுத்தல் செல்லுபடியாகவில்லை எனில் கட்டமைப்பு தோல்வியுறும்.
3. **உருவாக்கித் தருதல்** —
   - உறுப்புச் சரத்திற்கு, சரிபார்க்கப்பட்ட பொருளின் `toElementString()` திருப்பித் தரப்படுகிறது.
   - Digital Link-க்கு, ஒவ்வோர் உறுப்புக்கும் அதன் DL பங்கு ஒதுக்கப்படுகிறது (முதன்மைச் சாவி, சாவி தகுதிப்படுத்தி, அல்லது தரவுப் பண்பு); சாவி தகுதிப்படுத்தி வரிசை சரிபார்க்கப்படுகிறது; URI வெளியிடப்படுகிறது; பின்னர் **வெளியிடப்பட்ட URI-ஐ மீண்டும் பாகுபடுத்தி, அது செல்லுபடியாகும் Digital Link-ஆகவே திரும்பி வருகிறதா என உறுதி செய்யப்படுகிறது** — சர இணைப்பு மற்றும் விழுக்காடு-குறியாக்கப் படிக்கான பாதுகாப்புச் சோதனை இது. திரும்பி வரவில்லையெனில் `GaiaBuilderException` எறியப்படும்.

இது `DLSyntaxParser`-இல் உள்ள மறுகட்டமைப்புத் தருக்கத்தின் பிரதிபலிப்பே; எனவே பிரிப்பானின் இடமும் சரிபார்ப்பும் பாகுபடுத்தி எதிர்பார்ப்பதைப் போலவே சரியாக அமையும்.

## உறுப்புச் சரங்களைக் கட்டமைத்தல்

```java
String es = GaiaBuilder.create()
        .ai("01", "09506000134352")
        .buildElementString();
// 0109506000134352
```

- **AI** உடனடியாகச் சரிபார்க்கப்படுகிறது: அது அறியப்பட்ட GS1 பயன்பாட்டு அடையாளங்காட்டி இல்லையெனில் `ai(...)` `IllegalArgumentException` எறியும். (பாகுபடுத்தலுக்கு முன்பே கட்டமைப்பான் AI-ஐ மதிப்புடன் இணைக்கிறது; எனவே `"99999"` போன்ற அறியப்படாத அல்லது மிக நீளமான AI இங்கேயே பிடிபட வேண்டும் — இல்லையெனில் அது அமைதியாக வேறோர் AI-ஆக மறுஅடையாளமிடப்பட்டிருக்கும்.) **மதிப்பு** பின்னர், கட்டமைப்பு நேரத்தில் சரிபார்க்கப்படுகிறது.
- மதிப்புகள் கட்டுப்பாட்டு இலக்கம் உட்பட **முழுமையாக** இருக்க வேண்டும். கட்டமைப்பான் உங்களுக்காகக் கட்டுப்பாட்டு இலக்கத்தைக் கணக்கிடுவதுமில்லை, சேர்ப்பதுமில்லை — பார்க்க [கட்டுப்பாட்டு இலக்கங்கள்](#கடடபபடட-இலககஙகள).
- நீங்கள் சேர்த்த வரிசையிலேயே AI-கள் வெளியிடப்படும். GS1 அமைப்பு கோரும் இடங்களில் கட்டமைப்பானே FNC1 பிரிப்பான்களை இடுகிறது; அவற்றை நீங்கள் சேர்க்க வேண்டாம்.
- **எந்த AI-யும் இல்லாமல்** கட்டமைத்தால் வெற்று `getErrors()` பட்டியலுடன் `GaiaBuilderException("No AIs supplied")` எறியப்படும் — எந்த `GaiaError`-ஐயும் சுமக்காத ஒரே தோல்வி இதுவே.
- தன் வடிவ விதியிலோ கட்டுப்பாட்டு இலக்கத்திலோ மதிப்பு தோல்வியுறும் AI, கட்டமைப்பு முழுவதையுமே தோல்வியுறச் செய்யும்.

### பண்பு-AI-களுக்கு அவற்றின் அடையாளச் சாவி தேவை

பெரும்பாலான AI-கள் *பண்புகளே*; அவற்றுடன் ஓர் அடையாளச் சாவி இருக்க வேண்டும் என GS1 General Specifications கோருகிறது, கட்டமைப்பான் அதைச் செயல்படுத்துகிறது — முழுத் தொடரமைப்பு நிலை வழியாகவே சரிபார்க்கிறது, தப்பிக்க வழியில்லை. தனித்த தொகுதி/லாட் அல்லது வரிசை எண் செல்லுபடியாகும் உறுப்புச் சரம் **அல்ல**:

```java
GaiaBuilder.create().ai("10", "LOT-ABC").buildElementString();
// GaiaBuilderException: Cannot build a well-formed element string: 1 validation error(s)
//   [GE-S005] AI (10) requires 01 OR 02 OR 03 OR 8006 OR 8026 …

GaiaBuilder.create().ai("01", "09506000134352").ai("10", "LOT-ABC").buildElementString();
// 010950600013435210LOT-ABC        — the GTIN satisfies the requirement
```

அடையாளச் சாவிகள் (GTIN `01`, SSCC `00`, GLN `414`, …) மற்றும் நிறுவன-உள்ளக AI-கள் (`90`–`99`) முற்றிலும் நியாயமாகவே தனித்து நிற்க முடியும். மற்ற அனைத்திற்கும் ஒரு துணை தேவை.

> இந்தச் சரிபார்ப்பைத் தவிர்க்கும்படி `GaiaParser`-க்கு `ParseConfig.skipRequiresCheck(true)` மூலம் சொல்ல முடியும்; ஆனால் `GaiaBuilder` வேண்டுமென்றே அதற்கு இணையான ஒன்றைத் தருவதில்லை — தரநிலைக்கு இணக்கமான வெளியீட்டைத் தருவதே அதன் நோக்கம். வேண்டுமென்றே முழுமையற்ற உறுப்புச் சரத்தை இணைக்க விரும்பினால், அதை நீங்களே இணைத்து, சரிபார்ப்பை அணைத்துப் பாகுபடுத்துங்கள்.

## Digital Link URI-களைக் கட்டமைத்தல்

```java
// Canonical form (https://id.gs1.org)
String dl = GaiaBuilder.create()
        .ai("01", "09506000134352")
        .ai("21", "SERIAL123")
        .buildDigitalLinkUri();
// https://id.gs1.org/01/09506000134352/21/SERIAL123
```

செல்லுபடியாகும் Digital Link-க்குச் சரியாக ஒரே ஒரு **முதன்மை அடையாளச் சாவி** தேவை (எ.கா. GTIN `01`, GLN `414`, SSCC `00`). நீங்கள் தரும் ஒவ்வோர் AI-யையும் கட்டமைப்பான் வகைப்படுத்துகிறது:

| பங்கு | எப்படி உருவாக்கித் தரப்படுகிறது | எடுத்துக்காட்டு |
|------|-------------|---------|
| முதன்மை அடையாளச் சாவி | களம்/முன்னொட்டுக்குப் பிந்தைய பாதைத் துண்டு | `/01/09506000134352` |
| சாவி தகுதிப்படுத்தி (CPV `22`, தொகுதி `10`, வரிசை எண் `21`, …) | அதற்குப் பிந்தைய பாதைத் துண்டுகள், **§4.9 நியம வரிசையில்** (நீங்கள் சேர்த்த வரிசையில் அல்ல) | `/10/LOT-ABC` |
| தரவுப் பண்பு (மற்ற அனைத்தும்) | வினவல் அளபுருக்கள், **AI சாவியின்படி அகர வரிசையில்** (§4.12) | `?17=271231` |

உருவாக்கித் தரும்போது தகுதிப்படுத்திகள் மறுவரிசைப்படுத்தப்படுவதால், அவற்றை வரிசை பிறழத் தந்தாலும் தவறில்லை — `ai("10", …)`-க்கு முன் `ai("21", …)` தந்தாலும் `/10/LOT/21/SER` எனவே உருவாக்கித் தரப்படும். முதன்மைச் சாவிக்கு ஏற்புடையதாக இருக்க வேண்டியது அவற்றின் *தொகுப்பு* மட்டுமே.

பாதையிலும் வினவலிலும் உள்ள மதிப்புகள் விழுக்காடு-குறியாக்கம் செய்யப்படுகின்றன.

பின்வரும் சூழல்களில் கட்டமைப்பு தோல்வியுறும் (`GaiaBuilderException` எறியும், அல்லது தோல்வியுற்ற `BuildResult`-ஐத் திருப்பித் தரும்):

- AI-களுள் முதன்மை அடையாளச் சாவி **எதுவும்** இல்லாதபோது;
- **ஒன்றுக்கு மேற்பட்ட** முதன்மை அடையாளச் சாவிகள் இருக்கும்போது;
- ஏதேனும் AI Digital Link-இல் **தடைசெய்யப்பட்டிருக்கும்போது** (`03`, `8014`);
- தேர்ந்தெடுக்கப்பட்ட முதன்மைச் சாவிக்கு **சாவி தகுதிப்படுத்தி வரிசை** செல்லாததாக இருக்கும்போது (அந்தச் சாவியுடன் வராத தகுதிப்படுத்தி, அல்லது அனுமதிக்கப்பட்ட வரிசைக்கு வெளியிலான தகுதிப்படுத்திகள்).

## BuilderDigitalLinkConfig

திட்டம், களம், பாதை முன்னொட்டு, கூடுதல் வினவல் அளபுருக்கள், துண்டு ஆகியவற்றைக் கட்டுப்படுத்த ஒரு `BuilderDigitalLinkConfig`-ஐத் தாருங்கள்:

```java
import tools.pantheum.gaia.config.BuilderDigitalLinkConfig;

BuilderDigitalLinkConfig cfg = BuilderDigitalLinkConfig.builder()
        .baseUrl("https://example.com/resolver")   // sets scheme, domain, and path prefix at once
        .addQueryParam("context", "retail")        // appended after the AI data attributes
        .fragment("section-2")
        .build();

String dl = GaiaBuilder.create()
        .ai("01", "09506000134352")
        .buildDigitalLinkUri(cfg);
// https://example.com/resolver/01/09506000134352?context=retail#section-2
```

| கட்டமைப்பான் முறை | நோக்கம் | இயல்பு |
|----------------|---------|---------|
| `scheme(String)` | URI திட்டம்; `http` அல்லது `https` ஆக இருக்க வேண்டும் | `https` |
| `domain(String)` | தீர்ப்பான் அதிகாரம் — புரவலன் அல்லது `host:port` | `id.gs1.org` |
| `pathPrefix(String)` | முதல் முதன்மைச் சாவிக்கு முந்தைய பாதைத் துண்டுகள்; இரு முனைச் சாய்கோடுகள் இயல்பாக்கப்படும் | *(எதுவுமில்லை)* |
| `baseUrl(String)` | ஒரு URL-ஐ `scheme` + `domain` + `pathPrefix` எனப் பிரிக்கும் வசதி | — |
| `addQueryParam(String, String)` | கூடுதல் வினவல் அளபுரு; AI தரவுப் பண்புகளுக்குப் **பின்**, சேர்த்த வரிசையில் வரும்; விழுக்காடு-குறியாக்கம் செய்யப்படும் | — |
| `fragment(String)` | URI துண்டு (முன்னால் `#` இன்றி); விழுக்காடு-குறியாக்கம் செய்யப்படும் | *(எதுவுமில்லை)* |

`build()` அமைப்பை உடனடியாகச் சரிபார்க்கிறது: `http(s)` அல்லாத திட்டமோ வெற்றுக் களமோ `IllegalArgumentException` எறியும்.

- `BuilderDigitalLinkConfig.canonical()` (மாற்றுப்பெயர் `defaultConfig()`) என்பது எந்தக் கூடுதலும் இன்றி இயல்பான `https://id.gs1.org` — அளபுரு இல்லாத `buildDigitalLinkUri()` பயன்படுத்துவதும், `GS1AIObject.getCanonicalDigitalLink()` உருவாக்குவதும் சரியாக இதுவே.
- `baseUrl("http://id.example.org:8080/r")` → திட்டம் `http`, களம் `id.example.org:8080`, பாதை முன்னொட்டு `/r`.
- கூடுதல் வினவல் அளபுருக்கள் எப்போதும் AI-யிலிருந்து வந்த பண்புகளுக்குப் பின்னரே வரும்; எனவே நியம AI வரிசை (§4.12) பேணப்படுகிறது.

`BuilderDigitalLinkConfig` மாறாதது; ஒரே நிகழ்வைத் தயங்காமல் மீண்டும் மீண்டும் பயன்படுத்துங்கள்.

## சரிபார்ப்பும் பிழைகளும்

### விதிவிலக்கு எறியும் கட்டமைப்பு முறைகள்

AI-களால் நன்கமைந்த வெளியீட்டை உருவாக்க முடியாதபோது `buildElementString()`, `buildDigitalLinkUri()`, `buildDigitalLinkUri(BuilderDigitalLinkConfig)` ஆகியவை **`GaiaBuilderException`** (சோதிக்கப்படாத `RuntimeException`) எறிகின்றன:

```java
try {
    String es = GaiaBuilder.create().ai("01", "09506000134350").buildElementString();
} catch (GaiaBuilderException ex) {
    System.err.println(ex.getMessage());     // human-readable summary
    ex.getErrors().forEach(System.err::println);  // underlying GaiaError list
}
```

- **உள்ளடக்கத்** தோல்விகளில் (தவறான கட்டுப்பாட்டு இலக்கம், வடிவப் பொருந்தாமை, இல்லாத/தடைசெய்யப்பட்ட AI), `getErrors()` பாகுபடுத்தியின் `GaiaError` பொருள்களையே சுமக்கும் — [பாகுபடுத்தி வழிகாட்டியில் ஆவணப்படுத்தப்பட்ட](GaiaParser-Tamil.md#gaiaerror) அதே பொருள்கள்.
- **Digital Link அமைப்புத்** தோல்விகளில் (முதன்மைச் சாவி இல்லை, பல முதன்மைச் சாவிகள், தடைசெய்யப்பட்ட AI, செல்லாத சாவி தகுதிப்படுத்தி வரிசை), `getErrors()` கட்டமைப்பானின் மொழிக்கு உள்ளூர்மயமாக்கப்பட்ட ஒற்றை `GaiaError`-ஐச் சுமக்கும் (குறியீடு `GE-L008`, `GE-L012`, `GE-L013` அல்லது `GE-L014`).

### விதிவிலக்கு எறியாத tryBuild\* முறைகள்

உள்ளீடு பயனரிடமிருந்து வரும்போது, தோல்வி எதிர்பார்க்கத்தக்க, கையாளக்கூடிய விளைவாக இருக்கும்போது — விதிவிலக்குகளால் கட்டுப்பாட்டு ஓட்டத்தை நடத்துவதற்குப் பதிலாக `tryBuild*` வடிவங்களைப் பயன்படுத்துங்கள். அவை எறியாமல் ஒரு [`BuildResult`](#buildresult)-ஐத் திருப்பித் தருகின்றன:

```java
BuildResult r = GaiaBuilder.create()
        .ai("01", userValue)
        .tryBuildElementString();

if (r.isSuccess()) {
    use(r.getValue());
} else {
    report(r.getMessage(), r.getErrors());
}
```

| எறியும் | எறியாது |
|----------|--------------|
| `buildElementString()` | `tryBuildElementString()` |
| `buildDigitalLinkUri()` | `tryBuildDigitalLinkUri()` |
| `buildDigitalLinkUri(BuilderDigitalLinkConfig)` | `tryBuildDigitalLinkUri(BuilderDigitalLinkConfig)` |

ஒவ்வொரு `tryBuild*` முறையும் தன் எறியும் இணையுடன் அதே சரிபார்ப்பு மையத்தையே பகிர்ந்து கொள்கிறது; வேறுபாடு தோல்வி எல்லையில் மட்டுமே.

### பிழைச் செய்திகளின் மொழி

உள்ளடக்கச் சரிபார்ப்புப் பிழைகள் உள்ளூர்மயமாக்கப்பட்ட பிழைப் பட்டியலிலிருந்தே வருகின்றன. `GaiaBuilderException.getErrors()` / `BuildResult.getErrors()` சுமக்கும் `GaiaError` செய்திகளின் மொழியைத் தேர்ந்தெடுக்க `language(...)`-ஐ அழையுங்கள்; இயல்பு மொழி ஆங்கிலம்:

```java
BuildResult r = GaiaBuilder.create()
        .language(GaiaConstants.Language.FRENCH)
        .ai("01", userValue)
        .tryBuildElementString();
// r.getErrors() messages are in French
```

`GaiaParser` `ParseConfig` வழியாக ஏற்கும் அதே `GaiaConstants.Language` அமைப்பே இது; எனவே கட்டமைப்பானும் பாகுபடுத்தியும் ஒரே முறையிலேயே உள்ளூர்மயமாக்குகின்றன.

**உள்ளடக்கத்** தோல்விகளுக்கும் **Digital Link அமைப்புத்** தோல்விகளுக்கும் (முதன்மைச் சாவி இல்லை, பல முதன்மைச் சாவிகள், தடைசெய்யப்பட்ட AI, செல்லாத சாவி தகுதிப்படுத்தி வரிசை) — இவ்விரண்டின் `GaiaError` செய்திகளும் பொதுவான பிழைப் பட்டியல் வழியாகவே உள்ளூர்மயமாக்கப்படுகின்றன; பிந்தையது `GE-L008`, `GE-L012`, `GE-L013`, `GE-L014` குறியீடுகளைப் பயன்படுத்துகிறது.

### BuildResult

`BuildResult` (தொகுப்பு `tools.pantheum.gaia.result`) என்பது ஒரு `tryBuild*` அழைப்பின் விளைவை விவரிக்கும் மாறாத மதிப்பு-வகை:

| முறை | வெற்றியில் | தோல்வியில் |
|--------|------------|------------|
| `isSuccess()` | `true` | `false` |
| `getValue()` | உருவாக்கித் தரப்பட்ட சரம் | `null` |
| `getMessage()` | `null` | தோல்வியின் விளக்கம் |
| `getErrors()` | வெற்றுப் பட்டியல் | சரிபார்ப்புப் பிழைகள் (`GaiaBuilderException.getErrors()` இல் உள்ளவையே) |

## கட்டுப்பாட்டு இலக்கங்கள்

கட்டமைப்பான் கட்டுப்பாட்டு இலக்கங்களைச் சரிபார்க்கிறது, ஆனால் அவற்றைக் **கணக்கிடுவதில்லை** — உங்கள் மதிப்புகளில் கட்டுப்பாட்டு இலக்கம் ஏற்கெனவே இருக்க வேண்டும். ஒன்றைக் கணக்கிட `GS1Utils.calculateCheckDigit`-ஐப் பயன்படுத்துங்கள்:

```java
import tools.pantheum.gaia.gs1.util.GS1Utils;

int cd = GS1Utils.calculateCheckDigit("0950600013435");  // → 2
String gtin = "0950600013435" + cd;                      // 09506000134352
String es = GaiaBuilder.create().ai("01", gtin).buildElementString();
```

`calculateCheckDigit(String)` தரப்பட்ட இலக்கங்களின் மேல் நியமமான GS1 மட்டு-10 வழிமுறையைச் செயல்படுத்தி `0` முதல் `9` வரையிலான கட்டுப்பாட்டு இலக்கத்தைத் திருப்பித் தருகிறது; உள்ளீடு `null`-ஆகவோ வெற்றாகவோ எண்ணிலக்கமற்றதாகவோ இருந்தால் `-1`.

## இழைப் பாதுகாப்பு

`GaiaBuilder` இழை-பாதுகாப்பானது **அல்ல**; அது ஒருமுறை பயன்பாட்டுக்கே வடிவமைக்கப்பட்டது: `create()`-ஐ அழையுங்கள், AI-களைச் சேருங்கள், ஒருமுறை கட்டமையுங்கள். ஒவ்வொரு வெளியீட்டுக்கும் புதிய கட்டமைப்பானை உருவாக்குங்கள்; ஒரே கட்டமைப்பானைப் பல இழைகளில் பகிர வேண்டாம்.

`BuilderDigitalLinkConfig` (மற்றும் அதன் `BuildResult` வெளியீடுகள்) மாறாதவை, தயங்காமல் பகிரலாம் — தொடக்கத்தில் ஒரே அமைப்பைக் கட்டி, பல கட்டமைப்பான்களில் அதையே மீண்டும் பயன்படுத்துங்கள்.

## API குறிப்பேடு

### `GaiaBuilder`

| முறை | விளக்கம் |
|--------|-------------|
| `static GaiaBuilder create()` | புதிய, வெற்றுக் கட்டமைப்பானைத் தொடங்குகிறது. |
| `GaiaBuilder ai(String ai, String value)` | ஓர் AI-யையும் அதன் முழு மதிப்பையும் சேர்க்கிறது. இவ்விரண்டில் ஏதேனும் `null` எனில், அல்லது `ai` அறியப்பட்ட GS1 பயன்பாட்டு அடையாளங்காட்டி இல்லையெனில் `IllegalArgumentException` எறியும். |
| `GaiaBuilder language(GaiaConstants.Language language)` | உள்ளடக்கச் சரிபார்ப்புப் பிழைச் செய்திகளின் மொழியை அமைக்கிறது (இயல்பு ஆங்கிலம்). `null` புறக்கணிக்கப்படும். |
| `String buildElementString()` | GS1 உறுப்புச் சரத்தை உருவாக்கித் தருகிறது. தோல்வியில் `GaiaBuilderException` எறியும். |
| `String buildDigitalLinkUri()` | நியமமான Digital Link URI-ஐ உருவாக்கித் தருகிறது. தோல்வியில் `GaiaBuilderException` எறியும். |
| `String buildDigitalLinkUri(BuilderDigitalLinkConfig config)` | `config`-இன்படி Digital Link URI-ஐ உருவாக்கித் தருகிறது. தோல்வியில் `GaiaBuilderException` எறியும். |
| `BuildResult tryBuildElementString()` | விதிவிலக்கு எறியாத உறுப்புச் சரக் கட்டமைப்பு. |
| `BuildResult tryBuildDigitalLinkUri()` | விதிவிலக்கு எறியாத நியம Digital Link கட்டமைப்பு. |
| `BuildResult tryBuildDigitalLinkUri(BuilderDigitalLinkConfig config)` | `config`-இன்படி விதிவிலக்கு எறியாத Digital Link கட்டமைப்பு. |

### `BuilderDigitalLinkConfig`

| உறுப்பு | விளக்கம் |
|--------|-------------|
| `static BuilderDigitalLinkConfig canonical()` / `defaultConfig()` | இயல்பான `https://id.gs1.org`. |
| `static Builder builder()` | புதிய அமைப்புக் கட்டமைப்பான். |
| `getScheme()` / `getDomain()` / `getPathPrefix()` | தீர்க்கப்பட்ட திட்டம், தீர்ப்பான் அதிகாரம், பாதை முன்னொட்டு. |
| `getExtraQueryParams()` | கூடுதல் வினவல் அளபுருக்கள், சேர்த்த வரிசையில். |
| `getFragment()` | துண்டு, அல்லது `null`. |

### `GaiaBuilderException`

| உறுப்பு | விளக்கம் |
|--------|-------------|
| `getErrors()` | தோல்விக்குக் காரணமான `GaiaError` பொருள்கள் — உள்ளடக்கத் தோல்வியில் பாகுபடுத்தியின் பிழைகள், அல்லது ஒற்றை Digital Link அமைப்புப் பிழை (`GE-L008`/`GE-L012`/`GE-L013`/`GE-L014`). ஒருபோதும் `null` அல்ல. |

### `BuildResult`

| உறுப்பு | விளக்கம் |
|--------|-------------|
| `isSuccess()` | கட்டமைப்பு வெற்றியடைந்ததா. |
| `getValue()` | வெற்றியில் உருவாக்கித் தரப்பட்ட வெளியீடு; தோல்வியில் `null`. |
| `getMessage()` | தோல்வியில் தோல்வியின் விளக்கம்; வெற்றியில் `null`. |
| `getErrors()` | தோல்வியில் சரிபார்ப்புப் பிழைகள்; வெற்றியில் வெற்று. ஒருபோதும் `null` அல்ல. |
| `getTiming()` | கட்டமைப்புச் செயலுக்கான `ProcessingTiming` (தொடக்க நேரம், செயலாக்கக் காலம்), அல்லது `null`. |
